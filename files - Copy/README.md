# دانلودر اینستاگرام (ویدیو + آهنگ)

نسخه‌ی ساده‌شده: فقط از اینستاگرام دانلود می‌کند. دو دکمه دارد:
- **دانلود ویدیو** → فایل MP4 کامل
- **دانلود آهنگ** → فقط صدای همون پست، به MP3 تبدیل‌شده

## ساختار پروژه
```
videodl-project/
├── app.py
├── requirements.txt
├── cookies.txt          # باید خودتان بسازید (پایین توضیح داده شده)
├── templates/
│   └── index.html
├── static/
│   ├── style.css
│   └── script.js
└── downloads/
```

## مرحله ۱: نصب
```bash
cd videodl-project
py -m pip install -r requirements.txt
```
`ffmpeg` هم باید نصب باشد (برای تبدیل صدا به MP3).

## مرحله ۲: ساخت cookies.txt (اجباری)

اینستاگرام بدون این فایل درخواست دانلود را رد می‌کند.

1. در Chrome افزونه‌ی **Get cookies.txt LOCALLY** را از Chrome Web Store نصب کنید.
2. وارد instagram.com شوید و مطمئن شوید لاگین هستید.
3. روی آیکون افزونه کلیک کنید → **Export** را بزنید.
4. فایل دانلودشده را دقیقاً با نام `cookies.txt` کنار `app.py` قرار دهید (همان پوشه‌ای که `requirements.txt` هم آنجاست).

هر چند هفته یک‌بار که کوکی منقضی شد، همین مرحله را تکرار کنید.

## مرحله ۳: اجرا
```bash
py app.py
```
سپس در مرورگر بروید به: `http://localhost:5000`

## رفتار دانلود (گالری / موزیک)
وقتی فایل MP4 یا MP3 دانلود می‌شود، این‌که در گوشی داخل «گالری» یا «موزیک» نمایش داده شود به رفتار خودِ سیستم‌عامل و مرورگر بستگی دارد، نه چیزی که این سایت مستقیماً کنترل کند. اکثر گوشی‌های اندروید و آیفون فایل‌های ویدیویی و صوتیِ دانلودشده را خودکار در گالری/موزیک نمایش می‌دهند چون نوع فایل (MP4 / MP3) را تشخیص می‌دهند.

## عیب‌یابی
| خطا | راه‌حل |
|---|---|
| «فایل cookies.txt پیدا نشد» | مرحله ۲ را انجام دهید |
| «اینستاگرام دسترسی را رد کرد» | کوکی منقضی شده؛ دوباره اکسپورت بگیرید |
| «فقط لینک‌های اینستاگرام پشتیبانی می‌شوند» | لینک یوتیوب یا سایت دیگر وارد نکنید |
| خطای ffmpeg | ffmpeg را نصب و در PATH قرار دهید |

## نکته‌ی قانونی
فقط برای محتوای عمومی/شخصی استفاده کنید و به شرایط استفاده‌ی اینستاگرام و قوانین کپی‌رایت احترام بگذارید.

## ⚠️ هشدار امنیتی مهم درباره‌ی cookies.txt
فایل `cookies.txt` شامل نشست ورود واقعی حساب اینستاگرام شماست (sessionid، csrftoken و...).
هر کسی این فایل را داشته باشد، بدون رمز عبور می‌تواند وارد حساب شما شود.

- **هرگز** این فایل را در گیت‌هاب کامیت نکنید (فایل `.gitignore` همراه پروژه این را خودکار رد می‌کند).
- هرگز آن را در چت، ایمیل یا جای دیگری به اشتراک نگذارید.
- اگر هر زمان این فایل جایی لو رفت، فوراً از تنظیمات اینستاگرام همه‌ی نشست‌ها را Log out کنید یا رمز عبور را عوض کنید.

## دیپلوی آنلاین (Render + گیت‌هاب)

۱) این فایل‌ها را در یک ریپوی گیت‌هاب آپلود کنید (`cookies.txt` را **آپلود نکنید**، چون `.gitignore` هم همین را می‌گوید):
```
app.py, requirements.txt, Dockerfile, .gitignore, README.md,
templates/index.html, static/style.css, static/script.js, downloads/.gitkeep
```

۲) در Render یک «New Web Service» بسازید و همین ریپو را وصل کنید. چون یک `Dockerfile` در پروژه هست، Render خودش تشخیص می‌دهد و به‌جای Python معمولی، از Docker استفاده می‌کند (این باعث می‌شود `ffmpeg` هم نصب بشه).

۳) برای اضافه کردن `cookies.txt` به‌صورت امن (بدون گیت‌هاب):
- در پنل Render، وارد تنظیمات سرویس بشوید و بخش **Secret Files** را پیدا کنید.
- یک فایل مخفی جدید بسازید با مسیر (Filename) دقیقاً: `cookies.txt`
- محتوای فایل `cookies.txt` خودتان را داخلش پیست کنید و ذخیره کنید.
- Render این فایل را فقط روی سرور شما، در همان مسیری که `app.py` انتظارش را دارد قرار می‌دهد — هیچ‌وقت وارد گیت‌هاب نمی‌شود.

۴) روی Deploy بزنید.
